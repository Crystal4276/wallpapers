# Wallpapers

Fonds d'écran du bureau Quickshell (dépôt `qs-desktop`), clonés dans `~/Pictures/Wallpapers` par son `install.sh`.

| Dossier | Contenu | Utilisation |
|---|---|---|
| `simple/` | une image pour un écran | n'importe quel écran |
| `panorama/` | image très large (rapport > 2,5) | étalée sur plusieurs écrans côte à côte, découpée selon leur position réelle |
| `triptych/<nom>/{left,center,right}.png` | panorama déjà découpé pour 3 écrans | uniquement avec 3 écrans |

Triptyques :
- `green-storm` : original introuvable, seul ce découpage existe (2560x1440 / 3440x1440 / 2560x1440).
- `blame-city` : découpage du panorama `panorama/a_city_wallpaper__catppuccin_colors_1_2__Tsutomu_Nihei__Blame__colorfu_S635188153_St30_G7.jpeg`.

Les fonds animés (vidéos, WebP animés) ne sont pas versionnés.
